在 [X](https://x.com)（Twitter）时间线或贴文详情里，每条贴文的**分享按钮旁边**会出现一枚图片图标。点一下，图卡会复制到剪贴板，直接去微信或微博粘贴即可。复制失败时才会改为下载。

## 功能

- 一键出图，不用再复制链接去第三方网站
- 白底图卡，没有彩色外框，也没有二维码
- 保留头像、姓名、认证、正文、图片、视频封面、引用、链接预览、投票和互动数
- 导出库已打进脚本，不依赖 jsDelivr
- 时间线上被折叠的长贴文会提示打开详情，再复制全文
- 私密贴文只要你自己能看见，就可以导出

脚本只读取当前页面上的内容，不会把贴文发到第三方抓取服务。

## 使用

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)
2. 点击本页的「安装此脚本」
3. 打开或刷新 `https://x.com`
4. 点分享按钮旁的图片图标；看到「已复制」后即可去微信粘贴
